# Enterprise Active Directory Home Lab

## Executive Summary
This project documents the design and deployment of an Enterprise Active Directory Domain Services infrastructure. The environment is built using Windows PowerShell instead of a GUI Wizard to ensure repeatability.

---

## Objectives
* **Hands-on Competency:** Build and manage Windows Server using CLI methods to increase familiarity with the environment.
* **Real-World Troubleshooting:** Identify, resolve, and document practical problems that could occur when managing Windows Servers.
* **Operational Documentation:** Maintain technical documentation for easier troubleshooting in the future.
