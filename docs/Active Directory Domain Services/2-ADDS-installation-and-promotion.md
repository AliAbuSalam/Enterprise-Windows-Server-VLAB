# 1.Prerequisites
Before installing and promoting the server, make sure that the host meets the following condition:
- **Operating System:** Windows Server 2022.
- **Completed Phase 1 Staging State:**
  * **Hostname:** Updated to 'DC-01' (or whatever the name of the server will be).
  * **Network Configuration**: Assigned valid static IPv4 address on an isolated network interface. (default for this documentation: 192.168.50.10)
  * **DNS Setting:** DNS address is set to a loopback address (127.0.0.1).
- **Account Privileges**: Local Administrator Rights.
